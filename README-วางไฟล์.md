# Firebase — บัญชีบนคลาวด์ + ตั้งค่าใช้ร่วมกัน + ตารางลีกผู้เล่นจริง (12 ไฟล์)

ลากทั้งโฟลเดอร์ทับโปรเจกต์ · **แล้วรัน `npm install`** (มี dependency ใหม่: `firebase`)

```
ใหม่  src/features/cloud/firebase.ts             ตัวเชื่อม · ไม่มี env = ปิดโหมดคลาวด์
ใหม่  src/features/cloud/CloudAuthProvider.tsx   บัญชีบน Firebase Auth + Firestore
ใหม่  src/features/cloud/cloudConfig.ts          ตั้งค่าที่ทุกคนใช้ร่วมกัน
ใหม่  src/features/cloud/cloudLeague.ts          ตารางลีกข้ามผู้เล่น
แก้   src/features/auth/AuthContext.tsx          เลือก local หรือ cloud ตอนเปิดแอป
แก้   src/features/league/LeagueContext.tsx      ส่ง/ดึงตารางลีก
แก้   src/features/league/standings.ts           คิดอันดับจากผู้เล่นจริง
แก้   src/components/league/LeagueScreen.tsx     ตารางโชว์คนจริง
แก้   src/components/admin/AdminPanel.tsx        ปิดแผง = ส่งตั้งค่าขึ้นคลาวด์
แก้   src/components/admin/AdminBackup.tsx       ปุ่มส่ง/ดึงตั้งค่าจากคลาวด์
แก้   src/main.tsx                               ลำดับโหลดตั้งค่า
แก้   package.json · firestore.rules
```

## ตั้งค่า Firebase (ทำครั้งเดียว)

1. https://console.firebase.google.com → Add project
2. **Authentication** → Get started → Sign-in method → เปิด **Email/Password**
3. **Firestore Database** → Create database → **Production mode** → เลือก region
   (`asia-southeast1` ใกล้ไทยสุด)
4. แท็บ **Rules** → ลบของเดิมทิ้ง → ก๊อป `firestore.rules` ทั้งไฟล์ไปวาง → **Publish**
5. ⚙️ Project settings → Your apps → ไอคอน `</>` → ตั้งชื่อ → ก๊อปค่า 6 ตัวใน
   `firebaseConfig`
6. **Vercel** → Project → Settings → Environment Variables → ใส่ทั้ง 6 ตัว
   ชื่อตรงตาม `.env.example` (`VITE_FIREBASE_API_KEY` ฯลฯ) → **Redeploy**
7. เปิดเว็บ สมัครไอดีใหม่ 1 อัน (ไอดีเก่าอยู่ในเบราว์เซอร์ ย้ายขึ้นคลาวด์ไม่ได้
   อัตโนมัติ)
8. **ตั้งตัวเองเป็นแอดมิน**: Firestore → Start collection ชื่อ `admins` →
   Document ID = **uid ของคุณ** (ดูที่แท็บ Authentication) → ฟิลด์ไม่ต้องใส่อะไร → Save
9. รีเฟรชเว็บ ปุ่มแอดมินจะขึ้น

> อยากทดสอบในเครื่องก่อน: ก๊อป `.env.example` เป็น `.env` แล้วกรอกค่าเดียวกัน

## ได้อะไรบ้าง

### 1. ไอดีเดียวเล่นได้ทุกเครื่อง

รหัสผ่านอยู่กับ Firebase Auth ไม่ได้อยู่ใน Firestore — **นี่คือเหตุผลที่ยกโค้ดเดิม
ไปวางเฉย ๆ ไม่ได้** ของเดิมแฮชรหัสเองแล้วอ่านกลับมาเทียบในเบราว์เซอร์
ถ้าเอาโครงนั้นขึ้น Firestore ตรง ๆ = ทุกคนโหลดแฮชรหัสผ่านของคนอื่นได้

เกมยังล็อกอินด้วย**ชื่อผู้ใช้**เหมือนเดิม ระบบแปลงเป็นอีเมลหลังบ้านให้
(`ddx` → `ddx@players.fcallstar.local`) เติมอีเมลจริงทีหลังได้โดยไม่เสียไอดี

**ชื่อซ้ำกันไม่ได้จริง ๆ**: กฎ Firestore ให้ `usernames/{ชื่อ}` สร้างได้ครั้งเดียว
แก้ไม่ได้ ลบไม่ได้ สองคนชิงชื่อเดียวกันพร้อมกันจึงได้แค่คนเดียว

### 2. แอดมินแก้แล้วทุกคนเห็น

ปิดแผงแอดมินเมื่อไหร่ ตั้งค่าทั้งหมดถูกส่งขึ้น `config/admin` อัตโนมัติ
ผู้เล่นคนอื่นได้ของใหม่ตอนเปิดเกมครั้งถัดไป ไม่ต้อง deploy ใหม่

ลำดับตอนเปิดเกม: ไฟล์ใน repo ก่อน (กันกรณีออฟไลน์/ไม่มี Firebase) → **คลาวด์ทับ**
เพราะถ้าไม่ทับ คนที่เคยเปิดเกมวันแรกจะติดอยู่กับการ์ดชุดวันนั้นตลอดไป

มีเพดาน 900 KB ตรวจก่อนส่ง (ลิมิต Firestore คือ 1 MiB/document) เกินแล้วบอกตรง ๆ
ว่าให้ลดขนาดรูปแบนเนอร์ ดีกว่าส่งไปแล้วพังด้วย error ที่อ่านไม่รู้เรื่อง

### 3. ตารางลีกมีผู้เล่นจริง

แต่ละคนเขียนแถวของตัวเองที่ `league/{วันที่}/entries/{uid}` และอ่านของคนอื่นมาแสดง
**แถวคนอื่นเขียนไม่ได้** กฎบังคับว่า uid ใน path ต้องตรงกับคนที่ล็อกอินอยู่

- ผู้เล่นจริงขึ้นก่อน ทีมจำลองเติมส่วนที่เหลือให้ครบ 20 — คนเล่นเยอะขึ้น บอทก็ถูกดัน
  ออกจากท้ายตารางไปเอง ไม่ใช่จู่ ๆ ตารางเปลี่ยนโฉม
- **อันดับที่โชว์กับอันดับที่ใช้จ่ายรางวัลคิดจากชุดเดียวกัน** ถ้าแยกกันเมื่อไหร่
  ผู้เล่นมีสิทธิ์คิดว่าเกมโกง
- รีเฟรชทุก 2 นาที ไม่ใช่ realtime — ตารางที่ขยับระหว่างอ่านแย่กว่าตารางที่ช้าไปนาที
  และ listener ที่เปิดค้างทั้งวันคือค่าอ่านที่จ่ายฟรี ๆ
- เขียนขึ้นคลาวด์เฉพาะตอนมีนัดใหม่จบ ไม่ใช่ตั้งเวลาเขียน

## ข้อควรรู้

- **ไอดีเก่าในเบราว์เซอร์ไม่ย้ายขึ้นคลาวด์เอง** พอเปิดโหมดคลาวด์ ระบบล็อกอินจะ
  เปลี่ยนไปใช้ Firebase ทั้งหมด ต้องสมัครใหม่ · เซฟเก่ายังอยู่ในเครื่อง
  ถ้าอยากได้คืนให้ปิด env แล้วเปิดใหม่
- **ยังไม่ได้ทดสอบกับ Firebase จริง** ผมไม่มีโปรเจกต์ Firebase ให้ยิงทดสอบ
  โค้ดผ่าน typecheck สะอาดและไล่ตรรกะแล้ว แต่ของแบบนี้ต้องเจอของจริงถึงจะรู้
  ถ้าติดตรงไหน ส่ง error ใน Console (F12) มาได้เลย
- **ค่าใช้จ่าย** แผนฟรีของ Firebase ให้อ่าน 50,000 ครั้ง/วัน เขียน 20,000 ครั้ง/วัน
  ผู้เล่นหนึ่งคนใช้ราวไม่กี่สิบครั้งต่อวัน ระดับเพื่อนเล่นกันไม่มีทางถึง
