# การ์ดพิเศษ (special)

แอดมินตั้ง "รายการการ์ดพิเศษ" ได้หลายรายการ แต่ละรายการมี

- **การ์ด 11 ใบ** จากคลังการ์ด — ผู้เล่นต้องมีครบทุกใบในคลับถึงจะปลดล็อก
- **การ์ดพิเศษ 1 ใบ** ที่ขาย (เลือกระดับตีบวกที่ได้รับได้ +0 ถึง +8)
- **ราคาเป็น Special Point** (`wallet.special`)

## กติกา

- การ์ด 11 ใบเป็น "กุญแจ" ไม่ใช่ "ราคา" — ตอนซื้อไม่ถูกหักออกจากคลับ ใบไหนก็ได้ของนักเตะคนนั้น
  (ระดับตีบวกเท่าไรก็ได้ อยู่ในทีมตัวจริงหรือไม่ก็ได้ ติดล็อกในตลาดก็ได้)
- เทียบการ์ดด้วยกติกาเดียวกับตราทีม (`features/club/identity.ts` → `isSameCard`):
  ไอดีคลังตรงกัน → นับ · ถ้ามีเลขประจำตัวการ์ดทั้งสองฝั่ง เลขต้องตรงกัน ·
  ถ้าฝั่งไหนยังไม่มีเลข ต้องเป็น "การ์ดใบเดียวกัน" คือ OVR เท่ากัน **และ** ไฟล์รูปเดียวกัน
  (ใช้ชื่อแทนรูปเฉพาะตอนฝั่งไหนไม่มีรูปจริง) — ชื่อนักเตะอย่างเดียวไม่พอ
  เช่น MESSI 117 จากการผสมการ์ดไม่นับเป็น MESSI 122 ที่รายการต้องการ ·
  การ์ดที่ผู้เล่นได้ไปก่อนแอดมินลบแล้วสร้างใหม่ (ไอดีเก่า รูปเดิม OVR เดิม) ยังนับได้
- ช่องบนหน้าจอเติมให้อัตโนมัติจากการ์ดในคลับ โชว์ใบที่ตีบวกสูงสุดของคนนั้น
- ซื้อได้ **1 ครั้งต่อไอดีต่อรายการ** (`account.special.bought[offerId]`) — นับต่อบัญชี
  เพราะรายการเป็นค่าตั้งของแอดมินที่ผู้เล่นอ่านได้อย่างเดียว
- ตรวจครบทุกข้อก่อนหักเงิน (ระบบเปิด · รายการเปิด · ตั้งครบ 11 ใบและเลือกการ์ดขายแล้ว ·
  ยังไม่เคยซื้อ · มีครบ 11 · Special Point พอ · การ์ดขายยังอยู่ในคลัง · คลับไม่เต็ม)
  แล้วหัก Special Point + ส่งการ์ด + บันทึกว่าซื้อแล้ว ในบัญชีใหม่ก้อนเดียว — ไม่มีทางหักเงินแล้วไม่ได้การ์ด
- รายการที่ตั้งไม่ครบ 11 ใบหรือยังไม่เลือกการ์ดขาย จะไม่โชว์ให้ผู้เล่นเห็น

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `types.ts` | `SpecialOffer`, `SpecialConfig`, `SpecialProgress`, `SpecialError` |
| `constants.ts` | คีย์ `football-home-ui:special:v1`, `REQUIRED_CARDS = 11`, ค่าเริ่มต้น |
| `specialConfigStore.ts` | ซ่อมข้อมูลที่อ่านเข้ามา (ค่าตั้ง + ประวัติการซื้อของบัญชี), load/save |
| `special.ts` | กติกาล้วน ๆ: `slotsOf`, `filledCount`, `refuse`, `buy` |
| `SpecialContext.tsx` | `useSpecial()` — ค่าตั้ง, ประวัติการซื้อ, `buy(offerId)` |

หน้าจอ: `src/components/special/SpecialCardScreen.tsx` (ปุ่ม "การ์ดพิเศษ" แถบล่าง ถัดจากตีบวกการ์ด)
แอดมิน: `src/components/admin/AdminSpecial.tsx` (แท็บ "การ์ดพิเศษ")

ค่าตั้งอยู่ใต้ prefix `football-home-ui:` จึงไปกับไฟล์สำรอง, `public/config/admin.json`
และค่าตั้งบนคลาวด์โดยอัตโนมัติ
