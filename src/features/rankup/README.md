# rankup — ระบบตีบวกการ์ด

แทนที่เมนู "แลกเปลี่ยน" เดิมในแถบล่าง

## ภาพรวม

การ์ดที่ผู้เล่นมีทุกใบมีค่า `plus` (0–10) เก็บอยู่บน `OwnedPlayer` การตีบวกหนึ่งครั้งคือ

1. เลือก **การ์ดหลัก** (เป้าหมาย) หนึ่งใบ
2. ใส่ **การ์ดวัสดุ** ตามจำนวนที่ระดับนั้นกำหนด
3. จ่ายค่าธรรมเนียม แล้วสุ่มตามอัตราสำเร็จของระดับนั้น

สำเร็จ → `plus + 1` ล้มเหลว → ทำตาม `onFail` ของระดับนั้น
(`keep` / `down` / `reset` / `destroy`)

## ระดับทอง +9 / +10

`MAX_PLUS` = 10 และ `GOLD_PLUS_FROM` = 9 — ป้าย +9 และ +10 เป็นสีทองทุกที่ที่แสดง
ทุกจุดที่วาดป้าย +N กระจาย `goldPlusProps(plus)` ลงไป แล้วกฎ `[data-plus-gold]` ใน
`styles/globals.css` ทำให้เป็นทองแบบเดียวกันทั้งเกม เฟรมบนบันได +9/+10 ยังไม่มีภาพ
จึงวาดด้วยโค้ด (`components/rankup/RankFrame`) — มีภาพเมื่อไรเพิ่มใน `assetMap.ts`

config ที่บันทึกไว้ก่อนมีระดับ 9–10 มีแค่ 8 แถว ระดับ 9 และ 10 จึงใช้ค่าเริ่มต้น
(วัสดุ 5 ใบ, โอกาส 8% / 5%, โบนัส +27 / +34, ค่าธรรมเนียม 280,000 / 500,000)
จนกว่าแอดมินจะแก้

## ทำไม `plus` ไม่ใช่ `rating`

`syncOwned` เขียน `name`, `rating`, `position` ทับจากแคตตาล็อกทุกครั้งที่อ่านการ์ด
เพื่อให้แอดมินแก้การ์ดแล้วการ์ดที่คนถือไปแล้วเปลี่ยนตาม ถ้าเก็บโบนัสไว้ใน `rating`
โดยตรง มันจะถูกล้างทิ้งทุกครั้ง จึงเก็บแค่ระดับ แล้วบวกโบนัสตอนคำนวณแทน —
`ratingWithPlus()` ใน `plus.ts` คือจุดเดียวที่รวมสองค่านี้เข้าด้วยกัน

## ไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `types.ts` | รูปร่างของ config และผลลัพธ์ |
| `constants.ts` | บันไดค่าเริ่มต้น 1–10, คีย์ storage, เพดานต่าง ๆ, ระดับทอง |
| `plus.ts` | โบนัสเรตติ้ง — แยกไว้เบา ๆ ให้ `squad/rating.ts` เรียกได้ |
| `rankupConfigStore.ts` | อ่าน/เขียน/ซ่อม config + แคชสำหรับ `plusBonus` |
| `rankup.ts` | กฎ, การตรวจเงื่อนไข, และการสุ่ม |
| `RankUpContext.tsx` | provider ให้หน้าจอและแผงแอดมิน |

## การตั้งค่าในแผงแอดมิน

`ADMIN → ตีบวกการ์ด` แก้ได้ทุกระดับ: จำนวนวัสดุ, โอกาสสำเร็จ, โบนัสเรตติ้ง,
ค่าใช้จ่าย + สกุลเงิน, ผลเมื่อล้มเหลว และรายชื่อการ์ดที่ใช้เป็นวัสดุได้
(ปล่อยว่าง = ใช้การ์ดใบไหนก็ได้) รวมถึงอัปโหลดพื้นหลังของหน้าจอ

config อยู่ใน localStorage ใต้ prefix เดียวกับส่วนอื่น จึงถูกดูดขึ้น Firestore
พร้อมกับ snapshot ของแอดมินอัตโนมัติ — ไม่ต้องแก้ `backup.ts`
