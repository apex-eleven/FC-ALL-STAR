# รูปของกล่องสุ่ม (Lucky Box)

วางไฟล์ `.png` `.webp` `.gif` `.jpg` ไว้ในโฟลเดอร์นี้ แล้วไปใส่พาธที่
หน้า ADMIN → แท็บ "กล่องสุ่ม" → ช่อง "รูปของช่องนี้" หรือ "รูปหน้าปกกล่อง"

พาธที่ใส่ให้ขึ้นต้นด้วย `/lucky/` เสมอ เช่น

    /lucky/coin.gif
    /lucky/gem.webp
    /lucky/ticket.png

## ทำไมควรใช้วิธีนี้แทนการอัปโหลด

- **GIF ยังขยับได้เสมอ** — ไฟล์ถูกเสิร์ฟตรงจากเว็บ ไม่ผ่านการย่อ
- **ไม่กินพื้นที่เอกสารค่าตั้ง** ซึ่งจำกัดที่ 1 MB และผู้เล่นทุกคนต้องโหลดตอนเข้าเกม
- แก้รูปทีหลังได้โดยไม่ต้องแตะค่าตั้งในหน้า ADMIN เลย (ทับไฟล์ชื่อเดิม)

ปุ่ม "อัปโหลดรูป" ในหน้า ADMIN ยังใช้ได้ตามปกติ เหมาะกับรูปไม่กี่ใบที่อยากลองเร็ว ๆ
ไฟล์เล็กกว่า 48 KB จะถูกเก็บทั้งไฟล์ (GIF จึงยังขยับ) ไฟล์ใหญ่กว่านั้นจะถูกย่อ
และถ้าเป็น GIF จะกลายเป็นภาพนิ่ง
