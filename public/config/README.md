# public/config

`admin.json` คือข้อมูลตั้งค่าทั้งหมดของเกมที่ **ติดไปกับ repo**

- คลังการ์ด · แพ็ค/ร้านค้า · ดราฟต์ · อัตราสุ่ม · ลีก · แบนเนอร์ข่าว · walkout · อวตาร
- **ไม่มีข้อมูลไอดีผู้เล่นหรือรหัสผ่าน** — โฟลเดอร์ `public/` ถูกเสิร์ฟให้ทุกคนที่เปิดเว็บ

เขียนไฟล์นี้อัตโนมัติทุกครั้งที่ปิดแผงแอดมิน (เฉพาะตอนรัน `npm run dev`)
และกดบันทึกเองได้ที่แท็บ "สำรองข้อมูล"

ตอนเปิดเกมในเบราว์เซอร์ที่ยังไม่มีข้อมูล ระบบจะอ่านไฟล์นี้มาเติมให้เอง
**ไม่ทับของที่มีอยู่แล้ว**

คอมมิตไฟล์นี้ขึ้น git ด้วย — ย้ายเครื่องแล้วเปิดมาจะมีข้อมูลครบ
