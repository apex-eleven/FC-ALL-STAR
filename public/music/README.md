# public/music

เพลงพื้นหลังของเกม เสิร์ฟตรงจากโฟลเดอร์นี้ ไม่ผ่าน bundler
เหมือน `public/players/` — เปลี่ยนไฟล์แล้วรีเฟรช ไม่ต้อง build ใหม่

ไฟล์ที่ระบบมองหาตอนนี้:

```
public/music/time-bomb.mp3
```

## เพิ่มเพลงใหม่

1. วางไฟล์ที่นี่ เช่น `public/music/anthem.mp3`
2. เพิ่มหนึ่งบรรทัดใน `src/features/sound/tracks.ts`

```ts
{ id: 'anthem', title: 'Anthem', src: '/music/anthem.mp3', gain: 0.8 },
```

พอมีเกินหนึ่งเพลง ช่องเลือกเพลงจะโผล่ในเมนูตั้งค่าเอง
`gain` คือตัวคูณ 0..1 ใช้เกลี่ยเพลงที่มาสเตอร์มาดังไม่เท่ากัน ไม่ใส่ = 1

`id` ห้ามเปลี่ยนหลังปล่อยจริง เพราะเป็นค่าที่เซฟไว้ในเครื่องผู้เล่น
ถ้าลบเพลงที่มีคนเลือกอยู่ ระบบจะเด้งกลับไปเพลงแรกให้เอง ไม่ค้างเป็นไฟล์ 404

## ขนาดไฟล์

ทั้งโฟลเดอร์นี้ถูกดาวน์โหลดจาก Vercel ตอนผู้เล่นเปิดเกม
mp3 192kbps ยาว 3 นาทีราว 5 MB ซึ่งรับได้ แต่ถ้าจะใส่หลายเพลง
ลองลดเหลือ 128kbps ก่อน เสียงที่เล่นคลอใต้ UI แทบไม่ต่าง

```
ffmpeg -i เพลง.mp3 -b:a 128k -ac 2 public/music/เพลง.mp3
```
