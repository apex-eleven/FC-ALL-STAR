# public/brand

ไอคอนที่สลับได้โดยไม่ต้องแก้โค้ด วางไฟล์ชื่อตรงตามนี้แล้วรีเฟรชได้เลย

| ชื่อไฟล์ | ใช้ที่ไหน |
|---|---|
| `currencylarge_COIN.png` | ไอคอนหน้ามูลค่าทีม ในแผง "ทีมของฉัน" |
| `currencylarge_BATTLEPASS_CREDIT.png` | ไอคอนแถบ STAR PASS ด้านซ้ายของหน้าแรก |
| `ovrbanner_OVRBADGE_MASTER.png` | โล่ OVR ทั้งการ์ด CLUB หน้าแรก และแผง "ทีมของฉัน" |
| `league_banner.png` | ป้ายหัว DAILY LEAGUE / ลีกประจำวัน (ตัวหนังสืออยู่ในรูป) |
| `league_division.png` | ป้ายดิวิชั่น (ใช้เมื่อไม่มีไฟล์เฉพาะดิวิชั่น) |
| `league_division_1.png` `_2` `_3` | ป้ายดิวิชั่นแยกตามดิวิชั่น — เลขอยู่ในรูป |
| `league_title.png` | ป้ายหัวตารางคะแนน (ตัวหนังสืออยู่ในรูป) |
| `league_star.png` | ไอคอนดาวหน้า "อันดับปัจจุบัน" |
| `league_clock.png` | ไอคอนนาฬิกาหน้า "เวลาจบลีกวันนี้" |
| `league_trophy.png` | ถ้วยในหน้าสรุปผลตอนจบวัน |
| `league_background.jpg` | ภาพพื้นหลังหน้าลีก (ไม่มีไฟล์ = ใช้พื้นหลังไล่สีเดิม) |
| `manager_background.jpg` | ภาพพื้นหลังเมเนเจอร์โหมด 2048x942 (อัปโหลดในแผงแอดมินจะใช้รูปนั้นแทน) |
| `manager_figure.png` | ภาพนักเตะตรงกลางเมเนเจอร์โหมด PNG พื้นใส (อัปโหลดในแผงแอดมินจะใช้รูปนั้นแทน) |

- ไฟล์ในโฟลเดอร์นี้ **ไม่ผ่าน bundler** — Vite ก๊อปไปตรง ๆ เข้าถึงที่ `/brand/<ชื่อไฟล์>`
- ยังไม่มีไฟล์ก็ไม่พัง ระบบจะใช้ไอคอนเดิมที่อยู่ใน `src/assets/` แทนไปก่อน
- ขนาดที่เหมาะคือ 256x256 PNG พื้นหลังโปร่ง

ห้ามคอมมิตไฟล์ที่ติดลิขสิทธิ์หรือเครื่องหมายการค้าของคนอื่นเข้า git ตามกฎใน `CLAUDE.md`
