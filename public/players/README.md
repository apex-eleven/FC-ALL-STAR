# public/players

รูปการ์ดนักเตะวางไว้ในโฟลเดอร์นี้

- ไฟล์ในนี้ **ไม่ผ่าน bundler** — Vite ก๊อปทั้งโฟลเดอร์ไปตรง ๆ เข้าถึงได้ที่ `/players/<ชื่อไฟล์>`
- รองรับ `.webp` `.png` `.gif` `.jpg` `.avif` (ไฟล์ animated ใช้ได้)
- คลังการ์ดเก็บแค่ **ชื่อไฟล์** ไม่ได้เก็บ URL หรือตัวรูป
- วางไฟล์เสร็จแล้วรัน `npm run players:manifest` หนึ่งครั้ง เพื่อให้ตัวเลือกรูปในแอดมินเห็นไฟล์ใหม่

ห้ามคอมมิตรูปที่ติดลิขสิทธิ์ ตราสโมสร หรือหน้านักเตะจริงเข้า git ตามกฎใน `CLAUDE.md`
